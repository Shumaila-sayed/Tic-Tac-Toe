# Tic-Tac-Toe 🎮

A simple yet powerful **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. This project follows clean coding principles with **factory functions, and the module pattern** to ensure scalability and maintainability.

## 📌 Features
- **Object-Oriented Design**: Game logic is encapsulated within objects for better structure.
- **Smart Game Flow**: Prevents invalid moves and dynamically detects wins and ties.
- **Interactive UI**: Players can enter names, click to place markers, and receive real-time feedback.
- **Modular Codebase**: Uses factory functions and IIFE to minimize global variables.
- **Restart Functionality**: Players can start a new game at any time.

## 🚀 Technologies Used
- **HTML** – Structuring the game interface.
- **CSS** – Styling for a clean and engaging UI.
- **JavaScript** – Game logic, event handling, and DOM manipulation.
